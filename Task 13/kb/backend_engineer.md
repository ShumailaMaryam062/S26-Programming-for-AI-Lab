# Backend Engineer (Intern/Junior)

## What You Do
- Build and maintain REST APIs and backend services.
- Work with databases, caching, authentication, and integrations.
- Write tests, handle deployments, and monitor production systems.

## Core Skills
- Programming fundamentals (Python/Java/Kotlin/Node.js)
- REST API design, validation, versioning
- Databases: SQL (PostgreSQL/MySQL), indexing, migrations
- Caching basics (Redis)
- Testing (unit + integration)
- Linux/CLI basics

## Tools Often Expected
- Git/GitHub workflow (branching, PRs, reviews)
- Docker, Docker Compose
- CI/CD (GitHub Actions)
- Cloud basics (AWS/GCP)

## Portfolio Projects
- CRUD API with auth + PostgreSQL + Swagger + tests
- Background jobs with Redis queue
- Deploy containerized API to Cloud Run/ECS
