# Data Engineer (Intern/Junior)

## What You Do
- Build ETL pipelines, transform data, and load into databases/warehouses.
- Automate workflows and ensure reliability.

## Core Skills
- SQL joins and analytics basics
- Python for data processing
- Data modeling basics
- API ingestion and file formats (CSV/JSON)

## Tools Often Expected
- Airflow (or similar)
- Docker
- Cloud storage (S3/GCS)
- CI/CD

## Portfolio Projects
- ETL: public API -> storage -> cleaned tables in Postgres
- Airflow DAG with retries/alerts
